# بوت محرر المنشورات الاحترافي (Telegram Post Editor Bot)

هذا البوت مصمم لإدارة قنوات تيليجرام ونشر منشورات تحتوي على إيموجي مميز (Custom Emoji) حتى لو كان الأدمن لا يملك اشتراك Premium.

## المميزات
- دعم الإيموجي المميز عبر WebApp.
- دعم الوسائط (صور وفيديو).
- جدولة المنشورات.
- لوحة تحكم للمالك لإدارة الأدمنز والقنوات.
- استيراد قائمة الإيموجي عبر JSON.

## المتطلبات التقنية
- Python 3.10+
- aiogram v3
- FastAPI
- SQLAlchemy (SQLite)
- APScheduler

## طريقة التشغيل
1. قم بتثبيت المكتبات المطلوبة:
   ```bash
   pip install -r requirements.txt
   ```
2. قم بتعديل ملف `.env` وإضافة التوكن الخاص بك ورابط الـ WebApp.
3. قم بتهيئة قاعدة البيانات:
   ```bash
   python setup_db.py
   ```
4. لتشغيل البوت:
   ```bash
   python main.py
   ```
5. لتشغيل الـ WebApp (في سياق منفصل أو باستخدام reverse proxy):
   ```bash
   uvicorn webapp.router:app --host 0.0.0.0 --port 8000
   ```

## ملاحظات الأمان
- فقط المستخدمين المضافين في قاعدة البيانات كـ `admins` يمكنهم استخدام البوت.
- فقط الـ `owner` يمكنه إضافة أدمنز أو قنوات.
